# Trans Vault Release Notes

## Version 1.1.1

### IMPORTANT NOTE:
The minimum required Obsidian version is 1.13.0.
Please update Obsidian to the latest version to use the Trans Vault plugin. Thank you!

### Changed
- The plugin is adopted to the new API released with Obsidian 1.13.x.
- Minor UI fixes.


## Version 1.1.0

### Added

- Release notes can now be viewed from the settings menu.

### Changed

- The detection of the default attachment path in the destination vault defaults now to "off". No user interaction is required, as previous settings will not be changed.
